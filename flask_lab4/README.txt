Лабораторна робота №4 — Flask: request, сесії та cookie

Запуск у Windows:
1. Встановіть Python.
2. Відкрийте цю папку у VS Code.
3. У терміналі виконайте:
   py -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   py app.py
4. Відкрийте у браузері http://127.0.0.1:5000

Тестовий вхід:
Логін: admin
Пароль: 12345

Реалізовано:
- flash-повідомлення з категоріями;
- login/profile та перевірка сесії;
- вихід із системи;
- додавання cookie з терміном дії;
- видалення cookie за ключем і всіх cookie;
- таблиця поточних cookie;
- вибір світлої/темної теми, збережений у cookie.

Примітка: це навчальний приклад. Перед реальним розгортанням змініть secret_key,
вимкніть debug і використовуйте захищене HTTPS-з'єднання.
